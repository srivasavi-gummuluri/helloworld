# Hello World

A simple C learning repository for beginners.

## Description

This repository contains basic C programs to help learn the fundamentals of C programming.

## Contents

- `helloworld.c` - Classic "Hello, World!" program

## Getting Started

### Prerequisites

- GCC compiler (or any C compiler)

### Compilation

```bash
gcc helloworld.c -o helloworld
```

### Running

```bash
./helloworld
```
